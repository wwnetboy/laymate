## 标题与正文

### 三级小标题

正文段落用于解释、叙述和论证。段落之间空一行，由模板统一控制字号、行距与留白。

这是第二段正文，用于比较连续段落之间的间距。文章标题在正文之外，可以单独复制；章节标题由模板自动编号。

#### 四级小标题

需要更细的层级时，可以继续使用四级标题。

##### 五级小标题

五级标题保留结构层级，仍使用模板的小标题样式。

###### 六级小标题

六级标题用于展示解析支持范围，不建议日常文章堆叠过多层级。

## 文字强调与 Markdown 链接

### 加粗、斜体与行内代码

**加粗重点**用于突出一句中的关键内容。*斜体文字*用于语气或作品名称。短命令与文件名可以写成 `node --version`、`文章.md`。

### 高亮、下划线与删除线

==高亮文字==与 ++下划线文字++ 是两种独立的强调方式。~~这是一段已作废的表述~~ 用于展示删除线，不表示当前有效结论。

### 普通文字链接

[查看 Markdown 基础写法](https://commonmark.org/help/)是正文链接示例。文字链接也可以出现在来源组件内。

## 列表、检查清单与操作步骤

### 无序列表与嵌套列表

- 准备原始资料。
- 说明期待的结果。
  - 写清必须保留的内容。
  - 单独列出需要核对的细节。
- 将结果保存到容易找到的位置。

### 有序列表

1. 先准备内容。
2. 再查看结果。
3. 最后核对并保存。

### 指定起始序号的有序列表

3. 从第三项继续。
4. 保留原来的编号关系。

### 已完成与待完成的检查清单

- [x] 标题和正文已经核对。
- [x] 代码文字与原稿一致。
- [ ] 图片和链接仍待检查。

### 操作步骤：默认外观

:::steps
1. **准备材料**

   找到原始内容，确认资料完整。
2. **处理内容**

   选择相应功能，说明希望得到的结果。
3. **核对并保存**

   对照原稿检查关键细节，再保存最终文件。
:::

### 操作步骤：标题与续接编号

:::steps 从已有流程继续
3. **查看结果**

   确认当前输出符合要求。
4. **保存文件**

   选择目标目录并检查文件名。
:::

## 代码、高亮与终端窗口

代码窗口统一使用深色背景与苹果式圆点。下面的短示例覆盖当前语法颜色角色，不是要求读者执行的操作。

### JavaScript：注释、关键字、字符串、数值与函数

```javascript title=example.js
// 示例代码：保留原始文字与换行
const options = { name: "会议记录", count: 3 };

function describe(item) {
  return `${item.name}: ${item.count}`;
}

console.log(describe(options));
```

### Python：声明与元信息

```python title="示例 脚本.py"
#!/usr/bin/env python3
def greet(name):
    return f"Hello, {name}"

print(greet("读者"))
```

### HTML：标签与属性

```html title=example.html
<section class="sample">
  <p>这是一段示例文字。</p>
</section>
```

### JSON：配置内容

```json title=settings.json
{
  "name": "示例资料",
  "count": 3,
  "enabled": true
}
```

### PowerShell：变量与命令

```powershell
$articleName = "会议记录"
Write-Output $articleName
```

### Diff：增加与删除的颜色

```diff
--- old.txt
+++ new.txt
-旧的示例文字
+新的示例文字
 保持不变的文字
```

### Bash：命令脚本

```bash
# 终端命令示例
printf "准备开始\n"
```

### Shell：带提示符的终端记录

```shell
$ node --version
v24.0.0
```

### Text：普通操作口令

```text
准备内容 → 查看结果 → 核对细节 → 保存文件
```
